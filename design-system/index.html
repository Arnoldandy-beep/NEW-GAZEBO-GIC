How to use this in the Flask app

1 Copy design-system/css/gic-theme.css and design-system/js/theme.js into static/. They are dependency-free and sit alongside Bootstrap 5.
2 Add data-theme to the <html> tag in templates/base.html and link the stylesheet after Bootstrap.
3 Rebuild each module's markup with the .gic-* classes shown in the component kit; charts are inline SVG, so no charting library is required.
4 Keep the status → chip mapping in one Python dict (see the style guide) so every module renders the same badge for the same state.
